# R2K Gaming Lounge OS

A gaming lounge and cyber-café operations system concept.

## Project scope

The portfolio describes a desktop operations platform for gaming-lounge workflows, including kiosk-style management.

## Technologies listed in the portfolio

- React 19 and TypeScript
- Electron
- Socket.IO
- Windows kiosk controls

## Status

This repository currently contains project documentation only. Source code, installable builds, and operational usage evidence are not included.
